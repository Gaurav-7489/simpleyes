A. Enquiry form — connect it to Info@simplyes.de (owner does this in Formdall)

The website's form is ready but not yet connected; until then it offers WhatsApp and email. Formdall is the recommended EU form service (servers in Germany, data processing agreement included; free plan: 100 enquiries per month). Full step-by-step guide: docs/ENQUIRY-SETUP.md in the GitHub repository.

  1. Register at app.formdall.de/register using Info@simplyes.de and a strong password (not "Sign in with Google"). Accept the terms (this also concludes the data processing agreement, AVV) and confirm the email link.
  2. Turn on two-factor login. Under Settings → Data processing, enter the company details and download the AVV PDF.
  3. Create a form named SimplYes enquiry. Settings: allowed website simplyes.de; redirect URL empty; store submissions off; honeypot, disposable-address and deliverability checks on; captcha none.
  4. Field schema tab: mode reject; add the fields from https://simplyes.de/enquiry-schema.json.
  5. Actions tab: add an Email action to Info@simplyes.de with subject {{subject}}. No auto-reply yet.
  6. Embed tab: copy the two values below and send them to us (or enter them in Vercel yourself, see B).
